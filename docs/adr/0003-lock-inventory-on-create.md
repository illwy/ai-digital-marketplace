# 下单时锁定库存，支付成功后售出，超时释放

数字商品库存是离散的「一条资源」，不是可无限切分的数量。若等支付成功再分配，并发付款会造成超卖。下单时用 `SELECT ... FOR UPDATE` 取出一条 `AVAILABLE` 库存，改为 `LOCKED` 并写入订单；未支付超时任务把它改回 `AVAILABLE`；支付成功改为 `SOLD` 并写交付记录。

考虑过支付成功后再分配，以及用 Redis 预减库存。Redis 预减在进程崩溃时与 MySQL 对账成本更高；支付后再分配无法在下单瞬间告诉用户「有货」。MVP 不用消息队列，超时释放用 Spring 定时任务扫描过期锁定订单。
